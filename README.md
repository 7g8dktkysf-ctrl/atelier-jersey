# ATELIER JERSEY — Premium Custom Jersey Website

## Pages
- `index.html` — luxury landing page
- `collections.html` — 20 ready designs
- `customizer.html` — custom jersey studio
- `upload.html` — upload existing artwork

## Important
The current customizer includes a browser-based 360° rotation preview and generated pattern library. For a **true production-quality 3D jersey** with realistic fabric, seams and exact front/back/sleeve texture mapping, replace the CSS preview with your final `.glb`/`.gltf` jersey model and texture set.

The upload/order form is frontend-only. For real customer orders, connect it to a backend/database/storage and then add payment verification.

## GitHub Pages
Upload the whole folder to a GitHub repository. Keep the folder structure unchanged. Open `index.html` through GitHub Pages.
